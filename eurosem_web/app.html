EUROSEM v3.2L – planes

This web interface allows you to run EUROSEM v3.2L for cascades of planes, visualise the results, and save your input files and the output. Using the app means that you have agreed to the GNU General Public License (v3) associated with EUROSEM v3.2L.

Results are model estimates and depend on the parameters entered. They are provided without warranty and should not be the sole basis for engineering, safety, regulatory or financial decisions. You are responsible for checking the inputs and for any use of the results.

Sensitivity to parameter uncertainty

Runs the model again with one parameter at a time at its low and then its high value, everything else as in the form, and shows how much the outlet results change. Ranges come from the user guide for the soil texture chosen on each plane. Type your own low and high to use another range. This shows which inputs matter; it is not a confidence interval.

Run again after ticking more parameters or changing ranges; every run includes a fresh base case. Reset clears the results and returns the ranges and ticks to the guide defaults.
